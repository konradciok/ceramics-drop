### Storefront Surfaces

All storefront routes live under `src/app/[locale]/`. Route groups: `(collections)` (grids, has `loading.tsx`) and `(pdp)` (product pages, no `loading.tsx`).

- **Homepage** (`/`) — CMS-managed full-bleed hero (`page:home` document, admin editor `HomeHeroEditor.tsx`; see the CMS content layer in [product-registry.md](product-registry.md)) with a fallback to committed static images/copy when unpublished, then a card per ceramic family, a how-to-buy guide, editorial imagery and a pointer to the separate print shop (`printShopUrl(locale)` → https://anna-ciok.com). `force-dynamic` like other public catalog consumers.
- **Collection pages** — one per ceramic category (`/{category}`), grouped grids of tiles.
- **`/sklep` shop** — the ceramics shop (`src/app/[locale]/(collections)/sklep/page.tsx` → `CeramicShopScreen`): pieces on sale now plus a card per ceramic family, `CollectionPage` JSON-LD (`ceramicShopSchema`), `force-dynamic`. The nav Shop link points here. Until 2026-11-21 `/sklep` was the fine-art-print shop.
- **Retired print routes** — `/fine-art-prints`, `/fine-art-prints/{id}`, `/kolekcje` and `/kolekcje/{slug}` (all locales) answer **301** to the print shop at https://anna-ciok.com (`printShopRedirectTarget` in `src/lib/print-shop-redirects.ts`, called from `src/middleware.ts`; known designs map to their Shopify product handle, unknown ids and collection pages go to `/collections/all`). The header nav link and announce bar, the footer and `/sklep` link there too (`printShopUrl(locale)`, label `nav.fineArtPrints`).
- **`/showroom`** — pieces retired from a past drop into showroom state (visible, not purchasable — see `piece_state.showroom` in [database-schema.md](database-schema.md)); visitors can register interest via `/api/interest` (see [api-routes.md](api-routes.md)).
- **Individual product pages** — `/{category}/{id}` (e.g. `/kubki/k01`) in the `(pdp)` route group. Indexable URLs with SEO metadata, `Product` + `BreadcrumbList` JSON-LD, hreflang across all locales, a two-column layout, gallery, specs, add-to-cart island, and a live "more from this collection" strip (`pickPdpSiblings` in `src/lib/pdp-siblings.ts`: purchasable pieces first, topped up with sold/showroom ones; a sold PDP shows only purchasable pieces, and when its family has none left the strip is replaced by the newsletter signup). The `(pdp)` group deliberately has **no** `loading.tsx` so `notFound()` returns a real HTTP 404 (a parent Suspense boundary otherwise forces 200).
- **Lightbox** — quick-view modal on tiles; links to the product page permalink. Product photos always render at natural ratio, never cropped.
- **`/konto`** — customer accounts via **server-only Supabase Auth** (sessions are httpOnly cookies, verified locally with jose against the project JWKS — no browser Supabase client, no `NEXT_PUBLIC_*` key). Provider state (which sign-ins are live/enabled) is tracked in `docs/STATUS.md`; provider setup, Apple secret rotation, and the deletion runbook are in `docs/customer-accounts-runbook.md` (§1.3/§1.4 for Apple). Order history plus per-order detail/tracking at `/konto/zamowienia/[id]` (ownership-filtered, 404 on mismatch); a historical fine-art print order shows as shipped, without tracking (its Prodigi tracking tables were dropped), and its lines are labelled via `src/lib/legacy-print-lines.ts`. Both pages `force-dynamic` + noindex; the header `Konto` link is deliberately **static** (session-aware rendering there would flip the prerenderable `pl` tree dynamic). Fail-closed behind the `SUPABASE_PUBLISHABLE_KEY` secret: unset ⇒ pages render "accounts unavailable" and `/api/auth/*` 404. Plan: `docs/plans/customer-accounts.md`.
